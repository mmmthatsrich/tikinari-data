The per-source *_entries table is the curated landing zone — definition / POS / variant cleanups live there, not in JSON. Always go through import; never feed unify from JSON. unify is an idempotent DB→DB projection.

The Checklist · run from repo root, prefix PYTHONUTF8=1

1Identify source

Confirm which source with the user, and full re-scrape vs delta.

2Init + back up

py scripts/00_init_db.py then copy staging_dictionary.db → timestamped .bak. Never skip the backup.

3Run the recipe

Per-source recipe from docs/UPDATE_WORKFLOW.md. Web scrapes are long & resumable.

4Unify

py scripts/50_build_unified.py --source <name>. Skip for the etymology layer.

5Verify

py -m unittest discover -s tests. All must pass. For delta, report data_refresh_runs.

6Export app DB

py scripts/60_export_app_db.py rebuilds slim maori_dict.db from staging.

7Update trackers

Add a SESSIONS.md row (source, row counts, changes, date). Update DATABASE_REFERENCE.md only if counts / schema changed.
